# 3D-Hand-Gesture-Motion

A dynamic, interactive web application that combines real-time hand gesture tracking via **MediaPipe** with 3D particle animations, image overlays, and custom audio triggers powered by **Three.js**.

---

## ✨ Features

* **Real-time Hand Tracking**: Detects single and dual hand gestures through your webcam using MediaPipe Hands.
* **3D Particle Morphing**: Smooth particle transformations (Triangles, Squares, Circles, Hearts, and 3D Text) using Three.js.
* **Image Overlay Support**: Renders custom images/memes (e.g., *Absolute Cinema*) directly tied to specific gesture detections.
* **Smart Audio Triggers**: Plays gesture-specific sound effects accurately without audio looping/spamming during held gestures.
* **Popup Visualizer Window**: Renders all 3D Canvas visualizer elements in a dedicated pop-up window for clean presentations and content creation.

---

## 🛠️ Tech Stack

* **Language**: HTML5, CSS3, JavaScript (ES6+)
* **3D Engine**: [Three.js](https://threejs.org/)
* **Vision & AI**: [Google MediaPipe Hands](https://mediapipe.dev/)
